## What is Agentic AI?

Agentic AI is an AI system that can make decisions and take actions to achieve a goal.

It can:
- Understand the goal
- Decide the next step
- Use tools
- Check the result
- Repeat steps if needed
- Maintain memory/state


## Key Characteristics of Agentic AI

1. Autonomous - Can perform tasks with minimal human intervention.

2. Goal Oriented - Works towards achieving a specific goal.

3. Planning - Breaks a goal into smaller steps.

4. Reasoning - Decides what action to take next.

5. Adaptability - Changes its approach based on results.

6. Context Awareness - Understands and uses the current situation/context.


## Components of Agentic AI

1. Brain - The LLM that understands and reasons.

2. Orchestrator - Controls the workflow and decides which step runs next.

3. Tools - Allow the agent to perform actions.
   Example: Search, GitHub, database, APIs.

4. Memory - Stores useful past information/context.
